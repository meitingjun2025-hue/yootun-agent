# P3 小红书工作台 UI 布局对齐方案

状态：**已实施并通过 2026-11-23 用户真机验收**（X0 复核修订 R1–R6 见 [p3-xhs-workbench-baseline.md](p3-xhs-workbench-baseline.md) §1；验收记录见 [16-three-workbench-real-device-acceptance.md](16-three-workbench-real-device-acceptance.md)）。

本册是 [09-workbench-migration-plan.md](09-workbench-migration-plan.md) P3 小红书工作台的 UI 布局与交互契约。吸取 P2 视频号教训：只列组件栈会让实现重新发明导航与页面结构，导致布局返工（同类修订见 [11-wx-workbench-ui-layout-parity.md](11-wx-workbench-ui-layout-parity.md)）。本册把布局、信息架构和任务动线锚定到旧插件产品基准；设计规范仍以 [../plugin-ui-ux-standard.md](../plugin-ui-ux-standard.md) 和 [05-ui-ux.md](05-ui-ux.md) 为准。

## 1. 定案口径

旧插件的**布局、信息架构和任务动线**是 P3 UI 的产品基准；旧插件的**视觉与实现技术**不迁移。新版必须使用 PluginPageShell、官方 primitives、yootun kit、CSS Modules、主题 token、typed dictionary 和现行无障碍底盘重做。

| 层 | 处理 |
|---|---|
| 页面骨架 | 对齐旧插件 |
| 区域关系 | 对齐旧插件 |
| 顶级导航 | 对齐旧插件：爆款仿写 / 账号管理 / 车衣爆款看板 |
| 交互方式 | 对齐旧插件，包括素材组内上传拦截、任务取消确认、重新生成确认、看板写操作确认 |
| 信息密度 | 对齐旧插件，包括仿写两栏、账号双卡、看板四子区与 KPI 行 |
| 视觉样式 | 按 yootun 新规范重做 |
| DOM 与 CSS | 不迁移 `yxh-*` 类名、全局 style、inline style、旧色值、旧字体和旧几何 |
| 宿主形态 | 不恢复 sidebar footer 弹层；继续使用 root main 中央面板和 sidebar.panellist 入口 |

布局证据以旧仓库只读源码为准（未找到旧插件截图存档；X0 复核时如能运行旧插件，补拍三页 × 明暗截图存档）：

## 2. 页面总骨架

新版页面在 PluginPageShell 内重译旧布局：

```text
PluginPageShell
├─ PluginHeader
│  ├─ 小红书工作台
│  ├─ 小红书平台运营，包括内容创作、运营数据汇总与分析等常用功能
│  └─ 浏览器状态等全局辅助信息
├─ SegmentedTabs
│  ├─ 爆款仿写
│  ├─ 账号管理
│  └─ 车衣爆款看板
└─ Body
   ├─ 爆款仿写：两栏（素材 + 对标 | 文案内容）
   ├─ 账号管理：两栏（账号列表 | 账号主区）
   └─ 车衣爆款看板：子导航 + 四个子区
```

顶级导航只能是三个页面：

```text
爆款仿写 / 账号管理 / 车衣爆款看板
```

不得新增旧插件不存在的顶级 tab：

- 「素材」不是页面：素材选择与上传属于爆款仿写页左栏素材区；
- 「发布」不是页面：发布面板属于爆款仿写页文案结果区下方；
- 「创作」「看板」等泛化命名不得替换旧导航文案；
- 操作回执的落位见第 7 节，不得为新能力新增顶级导航；AssistantDock 为后期产品化能力，不在 P3 范围（D-6）。

## 3. 爆款仿写页

爆款仿写页使用两栏布局：

```text
左栏（素材 + 对标） | 右栏（文案内容区）
```

### 3.1 左栏：素材区

素材区从上到下：

```text
素材区
├─ 图片 / 视频 子 tab
├─ 素材缩略列表
├─ 主题（可选，图片与视频共用）
├─ 文案方向（可选）
└─ 理解视频内容开关（仅视频子 tab）
```

交互契约：

- 图片子 tab：多选上传，上限 9 个（对齐旧插件，已定案见 §8 决策点 4），缩略图带进度覆盖层与移除；
- 视频子 tab：单素材，重选覆盖旧视频（先停止旧轮询再启动新上传）；
- 上传中的素材可单独移除；上传失败显示错误并允许重选；
- 「理解视频内容」默认关闭，仅视频子 tab 显示并传递，开启时提示耗时较长；
- 主题与文案方向最大 500 字，是可选输入；
- 上传失败不丢表单：主题、方向、对标输入与已上传素材保持原状。

### 3.2 左栏：对标区与提交

```text
对标区
├─ 对标笔记（可选，笔记链接）
└─ 对标账号（可选，账号名称）

提交行
├─ [开始生成]
└─ [取消任务]
```

交互契约：

- 提交只拦截当前素材组（图片子 tab 或视频子 tab），不跨 tab 拦截；
- 素材组内存在 uploading 素材时按钮进入等待态并提示；
- failed 或无公网 URL 的素材不得进入任务创建；
- 取消任务需确认弹层，确认后取消当前任务；
- 任务创建生成新幂等键；同一任务重试复用原键的规则由 Host 契约定义。

### 3.3 右栏：文案内容区

右栏按任务状态切换，不显示成独立页面：

| 状态 | 呈现 |
|---|---|
| 空态 | 引导上传素材后点击开始生成 |
| 生成中 | 进度指示 + 当前步骤（素材下载 / 媒体探测 / 语音转写 / 转写校对…） |
| 已生成 | 可编辑结果卡 + 操作行 + 发布面板 |
| 失败 | 错误 + 失败步骤 + 保留输入的修复提示 |
| 已取消 | 取消终态，输入与素材保留 |

已生成状态的结构：

```text
文案结果卡（标题 / 正文 / 标签可编辑，标记「已生成 · 可编辑」）
├─ 只读附属行：封面文案 / 评论引导 / 图文分页文案（结果存在时展示，不可编辑）
├─ 风险提示
├─ 操作行：重新生成（确认） / 复制全文 / 保存编辑
└─ 发布面板：发布到小红书
   ├─ 发布账号选择
   ├─ 说明：打开创作者中心发布页，粘贴文案、自行上传素材、手动发布
   └─ [打开创作者中心] + 打开进度轮询
```

- 重新生成前必须确认；确认后以当前表单内容重新创建任务；
- 生成结果固定单版（versionCount 固定 1，对齐旧插件 RQ-2026-002），不做多版本对比视图；
- 复制全文把标题、正文、标签文本化进剪贴板并给出短暂反馈；
- 发布按当前素材类型直达图文 / 视频发布页，运行中轮询 publish.status；
- 失败态区分「素材缺少有效事实且无对标」等稳定原因，不把服务失败伪装成空态。

## 4. 账号管理页

账号管理页使用两栏布局：

```text
账号列表（左） | 账号主区（右）
```

Chrome 缺失时页面顶部显示阻断提示：扫码与采集不可用。

### 4.1 左栏：账号列表

```text
账号管理 + [添加账号]
└─ 说明：添加账号后在系统 Google Chrome 中扫码登录，会话仅保存在本设备
└─ 登录中提示
└─ 账号卡片列表
└─ 空态：还没有账号，点击添加账号扫码登录
```

账号卡片：

- 头像或安全占位、昵称（缺省显示账号 ID）、等宽账号 ID；
- 会话状态徽标：有效 / 过期 / 未知，检测中显示探测态；
- 发布窗口打开中：该账号存在进行中的发布 run（浏览器发布页仍打开）时，会话徽标旁显示警示状态点与「发布窗口打开中」，悬停说明「关闭后可继续登录、探测、采集或移除」；窗口关闭（发布 run 落终态）后标识消失（2026-11-26 采集取消与发布窗口状态单 §2.3）；
- 操作：检测、重新登录、移除本地（确认后执行）；
- 登录等待或任一账号运行探测 / 采集时，列表操作按旧规则禁用。

### 4.2 右栏：账号主区

```text
通知条（成功 / 错误，可关闭）
└─ 工具栏：[采集数据] [刷新数据]
└─ 账号信息卡：昵称 / 账号 ID / 授权状态
└─ 基本数据卡：笔记数、播放、点赞、收藏、评论、分享 + 最近采集时间
```

- 采集运行中按钮显示「取消采集」（点击取消本次采集），页数与笔记进度在工具栏内与按钮并排显示；取消为终态：提示「已取消，未保存本次采集」，不写本次快照，锁释放后账号可立即再次采集；自然结束（完成 / 失败）后按钮恢复「采集数据」，不再发取消请求（2026-11-26 采集取消与发布窗口状态单 §2.1）；
- 采集触达单次页数上限时显示截断警示（结果可能不完整，可再次采集）；
- 指标缺失显示缺口提示，不补 0；
- 未选中账号时右栏显示加载或空态。

## 5. 车衣爆款看板页

看板页在顶级 tab 内使用二级子导航，不新增顶级页面：

```text
车衣爆款看板
├─ 案例看板
├─ 关键词与扩词（AI 扩词待审候选角标，R7）
├─ 标签与 AI 标记（标签总数角标，R7）
└─ 采集与规则
```

页面级公共元素：

- 写操作通知条：成功 / 失败均可关闭，失败保留原数据；
- 页面加载失败显示错误与重试，不与业务空态混淆；
- 所有写操作（打标、排除、关键词保存与启停、候选裁决、标签提案裁决、标签保存、手动运行）先确认，携带幂等键。

### 5.1 案例看板

```text
KPI 行
├─ 筛选行：时间窗 / 关键词 / 款式 / 颜色 / 笔记词 / 评论词 / 综合分下限 / 排序 / 仅主记录 / 仅已打标
├─ 已启用筛选 chips（单个移除 / 一键清空）
├─ 案例表格（服务端分页）
└─ 笔记详情抽屉 + 图片灯箱 + 运行历史抽屉
```

- KPI 口径：当前筛选下案例数、本轮采集覆盖率、AI 标记完成率、重复素材组数等，以服务端 overview 投影为准；
- 时间窗固定三档：近 7 天 / 近 30 天 / 近 90 天；
- 排序枚举：综合分 / 发布时间 / 采集时间 / 点赞 / 评论 / 分享；
- 案例行：缩略图（缺失或加载失败显示图文 / 视频占位）、标题与话题、综合分、发布时间、互动指标、相似素材、操作；
- 笔记详情以抽屉呈现：正文话题高亮、图片灯箱、指标、相似素材、打标与排除入口；
- 运行历史以抽屉呈现，可查看 run 状态与批次；
- 容器 1100px 以下表格转为逐行卡片（标签 + 值），不出现横向裁切。

### 5.2 关键词与扩词

```text
关键词面板（正式关键词管理）
├─ 筛选行：类目 / 状态 / 来源
├─ 新增关键词行内表单（关键词 + 类目，确认 + 幂等键）
└─ 关键词列表：关键词 / 类目 / 状态 / 来源 / 操作（启用 ↔ 停用，确认 + 幂等键）

扩词候选审核面板（AI 扩词候选）
├─ 筛选行：状态（默认待审核）/ 类目 / 扩词起止日期
├─ 批量操作行：已选 n + [接受] [拒绝]（确认 + 幂等键，单次 ≤50）
└─ 候选列表：选择 / 关键词 / 类目 / 评分 / 理由 / 状态
```

- 关键词新增与启停保存前确认；保存失败列表保持原状；
- 扩词候选为多选批量裁决，行级失败逐条披露（partial 文案），完成后刷新待审候选角标；
- 「关键词与扩词」子导航角标显示 AI 扩词待审候选总数（R7，2026-11-21 用户指认为旧版 40 的实际口径）；

### 5.3 标签与 AI 标记

```text
AI 建议面板（AI 候选标签提案）
├─ 筛选行：提案状态（默认待确认）
├─ 提案列表：标签 / 维度 / 置信度 / 证据数 / 操作（接受 / 拒绝 / 合并）
└─ 合并目标标签选择（存在待审提案时显示）

标签管理面板（正式标签库）
├─ 筛选行：维度 / 状态 + [新增标签]
├─ 就近编辑卡（新增含编码与维度；编辑锁定编码与维度，确认 + 幂等键）
└─ 标签列表：标签 / 编码 / 别名 / 维度 / 状态 / 操作（编辑 / 启用 ↔ 退役）
```

- 提案接受 / 拒绝 / 合并各有确认路径；合并需先选择目标标签，未选择时合并不生效；
- 标签编辑使用就近编辑卡，不跳转页面；编辑不改编码与维度（服务端同约束）；
- 「标签与 AI 标记」子导航角标常驻显示标签总数（R7，同 §5.2 口径）；
- 审核失败保留原列表与原选中项。

### 5.4 采集与规则

```text
采集面板
├─ 说明：手动增量按启用关键词发起一轮采集，受每日搜索额度限制
├─ [手动增量采集]（确认 + 幂等键） + [运行历史]
└─ 运行中进度经「运行历史」抽屉查看，失败可重试

规则面板（只读）
├─ 说明：采集与评分口径由服务端部署配置统一下发，页面只读展示
├─ 定时采集徽标（已启用 / 已停用）+ 调度时间可读描述
└─ 只读配置行（发布窗口 / 每词上限 / 评论参数 / 去重阈值 / 检索与详情额度 / 规则版本）
```

- 配置全部只读：仅 scheduleEnabled 在服务端真实生效，页面以徽标展示，不提供编辑入口（旧插件 2026-10-13 裁决；服务端 settings_update 仅受理 scheduleEnabled，其余字段返回 XHS_HOTBOARD_SETTING_TOML_MANAGED）；
- `hotboard.settingsUpdate` Host action 保留（对齐旧 Host 与 09 册 action 面），UI 不调用；
- 运行启动携带 confirm 与幂等键；运行中可查看状态，失败可重试。

## 6. 响应式与容器断点

断点以 PluginPageShell 容器宽为准（旧插件使用 `yxh-root` 容器查询，新版使用 kit 稳定容器名）：

| 容器宽 | 布局 |
|---|---|
| 宽于 1120px | 仿写两栏按原比例；账号页 300px 列表 + 主区；看板表格完整列 |
| 1120px | 仿写两栏压缩（无固定最小列宽）；账号列表收窄至约 240px；看板表格转逐行卡片 |
| 900px | 仿写 / 账号页单列堆叠；看板 KPI 两列；页面边距收窄 |
| 640px | 统计卡单列；键值行与发布行换行；其余堆叠形态不变 |

键盘与无障碍要求沿用 05 册与 plugin-ui-ux-standard：全部操作可达、弹层与抽屉管理焦点回归、reduced-motion 关闭装饰动效。

## 7. 新增能力的落位

以下能力是 09 册为 P3 新增的，旧插件没有对应页面；落位不得破坏旧布局：

| 能力 | 落位 |
|---|---|
| 操作回执 | 就近呈现：任务回执在文案内容区，审核 / 关键词 / 设置回执在对应面板，上传回执在素材区 |
| 素材状态汇总 | PluginHeader 辅助信息位 + 仿写页素材区详情，不独立成页 |
| run 查询 | 看板「采集与规则」的运行历史抽屉；任务查询走文案内容区状态 |
